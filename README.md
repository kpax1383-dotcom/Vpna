# Amnezia для Android

> English: an Android VPN client (Kotlin, Jetpack Compose, sing-box `libbox`) with Happ-compatible subscriptions (HWID headers),
> Clash / Xray / sing-box / WireGuard import, per-app VPN, ping and traffic stats. See the sections below (in Russian).

Android-версия нашего клиента: тот же дизайн, та же логика подписок (HWID и заголовки как у Happ, ответы провайдера,
разбор ссылок, сборка конфига sing-box). Интерфейс на Jetpack Compose, VPN через `VpnService`, ядро — sing-box (`libbox`).

## Статус (честно)
- Исходники **не компилировались** в среде, где я их писал (там нет Kotlin/Android SDK). Проверены только баланс скобок и логика.
  Первая сборка может выдать мелкие ошибки компиляции: присылайте текст, поправлю.
- Всё, кроме туннеля, работает без ядра: добавление подписок, список серверов, настройки.
- `app/src/withCore/.../LibboxCore.kt` написан по документации libbox 1.12 и **не сверен с вашим AAR** (подробности в шапке файла).

## Сборка и выпуск на GitHub
1. Создайте репозиторий и залейте проект:

        git remote add origin https://github.com/<вы>/<репозиторий>.git
        git push -u origin main

2. **CI** (`.github/workflows/android.yml`) на каждый push и pull request гоняет юнит-тесты и собирает APK **без ядра**
   (artifact `Amnezia-apk-no-core`).
3. **Ядро**: Actions → `libbox` → Run workflow. Соберёт `libbox.aar` из исходников sing-box (artifact `libbox-aar`).
4. **Релиз с VPN-ядром**: поставьте тег, и workflow `release` соберёт ядро, потом APK и приложит его к GitHub Release:

        git tag v0.1.0 && git push origin v0.1.0

   Если ядро не собралось, APK всё равно выйдет, но без ядра (это написано в описании релиза).
5. **Локально**: Android Studio → Open (Gradle wrapper создастся сам) или `gradle :app:assembleRelease` (JDK 17, Android SDK 35, Gradle 8.10+).

APK подписывается debug-ключом: для личной установки этого достаточно. Для публикации подпишите своим ключом.
Workflow `libbox.yml` написан по памяти о сборке sing-box и не запускался: если цели `make` в вашей версии называются иначе, поправьте две строки `make`.

## Ядро sing-box (чтобы работал VPN)
Положите `libbox.aar` в `app/libs/` и пересоберите: Gradle подключит `src/withCore` вместо заглушки.
`libbox.aar` собирается из исходников sing-box (нужны Go, JDK, Android SDK и NDK):

    git clone https://github.com/SagerNet/sing-box && cd sing-box
    git checkout v1.12.12      # та же версия, что в десктопной версии
    make lib_install && make lib_android      # цели смотрите в Makefile вашей версии

Не берите бинарник `sing-box` из релизов и не доставайте файлы из чужого APK: нужна именно Java/JNI-обёртка (`libbox.aar`).
Если после добавления AAR сборка ругается на `LibboxCore.kt`, выполните команды из шапки файла (`javap`) и пришлите вывод.

## Что уже есть
- Подписки: `https://…`, `happ://add/…`, `amnezia://add/…`; HWID + `x-device-*` заголовки, повтор запроса «как Happ»,
  сообщение провайдера и лимит устройств в тексте ошибки, автообновление, остаток трафика.
- Импорт: ссылки vless / vmess / trojan / ss / hysteria2 / socks, base64-списки, **Clash/Mihomo YAML, Xray JSON, sing-box JSON,
  WireGuard `.conf`**; из буфера обмена или из файла (кнопка «Файл» в окне добавления).
- Конфиг: TUN, sniffing, DNS (udp / https / tls), фрагментация TLS, uTLS, мультиплексирование.
- **Пинг** (TCP) по всем серверам; для hysteria2 и WireGuard пинга нет (у них нет TCP-порта). Измеряется при отключённом VPN.
- **Скорость и трафик сессии** на главном экране. Берётся из счётчиков самого приложения (`TrafficStats`): ядро гонит весь
  трафик через этот процесс, так что это объём туннеля вместе с накладными расходами. На части устройств счётчик недоступен.
- **VPN по приложениям** (все / только выбранные / все, кроме выбранных): Настройки → «VPN по приложениям». Применяется при следующем подключении.
- **Лог** (Настройки → «Лог»): события подключения и сообщения ядра, с копированием.
- Русский и английский.

## Чего нет
- **OpenVPN**: ядро sing-box его не поддерживает, на ПК это был отдельный `openvpn.exe`. Для Android нужна отдельная библиотека
  (например, ics-openvpn / OpenVPN 3) и свой сервис; профили `.ovpn` приложение сейчас отклоняет с понятным сообщением.
- Сканирование QR-кодов, мониторинг подключений в реальном времени (Clash API), прокси-цепочки.
